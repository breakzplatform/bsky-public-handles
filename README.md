# Bluesky Public Handles

Website: [handles.notx.blue](https://handles.notx.blue)

A community list of public Bluesky handle domains: domains under which anyone
can get a handle such as `yourname.example.com`.

The list lives in [`data/handles.json`](data/handles.json) (described by
[`data/handles.schema.json`](data/handles.schema.json)). The table below and the
website are generated from that file.

**Status** is updated by a weekly automated check: a domain is marked
Deprecated after it fails two checks in a row (the domain no longer exists, is
parked or for sale, or handles under it no longer resolve) and goes back to
Active as soon as it passes again. **Last checked** is the date of the last
completed check.

## Add your domain

Run a domain where anyone can get a Bluesky handle? Add it to the list:

- **Open an issue** with the
  [Add a domain form](https://github.com/breakzplatform/bsky-public-handles/issues/new?template=add-domain.yml)
  and a maintainer will add it; or
- **Open a pull request** that adds an entry to
  [`data/handles.json`](data/handles.json), keeping the list in alphabetical
  order, then run `npm ci`, `npm run validate` and `npm run readme` and commit
  the regenerated README.

To be listed, a domain must let anyone get a handle (free, paid or freemium:
start the description with `[PAID]` or `[FREEMIUM]` when it is not free), have
a page explaining how to get one, and have at least one working handle under
it.

## Maintenance scripts

| Command                | What it does                                                          |
| ---------------------- | --------------------------------------------------------------------- |
| `npm run validate`     | Validate `data/handles.json` against the schema                       |
| `npm run check`        | Check every domain and update status, last checked and check details  |
| `npm run readme`       | Regenerate the table above from `data/handles.json`                   |
| `npm run readme:check` | Fail if the table is out of date                                      |

The checker needs Node 20 or newer and no dependencies.
